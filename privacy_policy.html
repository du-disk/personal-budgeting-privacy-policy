Kebijakan Privasi

Terakhir diperbarui: 14 April 2026

Terima kasih telah menggunakan aplikasi Personal Budgeting. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan membagikan informasi Anda saat menggunakan aplikasi kami ("Layanan").

1. Informasi yang Kami Kumpulkan

Aplikasi ini mengumpulkan beberapa kategori data agar dapat berfungsi secara normal:

  • Informasi Pendaftaran dan Akun: Saat Anda mendaftar melalui Google Sign-In, kami menerima informasi dasar seperti nama, alamat email, dan foto profil Anda.
  • Data Keuangan dan Transaksi: Data yang Anda masukkan (pemasukan, pengeluaran, saldo) disimpan di layanan cloud (Firebase/Firestore) agar Anda dapat mengakses sinkronisasi di berbagai perangkat Anda.
  • Akses Mikrofon dan Audio (Speech-to-Text): Aplikasi dapat meminta izin akses ke mikrofon Anda untuk menggunakan fitur konversi suara ke teks. Data suara TIDAK KAMI REKAM atau SIMPAN di server kami, tetapi langsung dialihkan ke layanan pengenalan suara bawaan untuk diubah menjadi teks transaksi.
  • Akses Kamera dan Galeri (Image Picker): Jika Anda mengunggah bukti transaksi berupa foto, kami memerlukan izin kamera/galeri. Foto diunggah menggunakan Firebase Storage dan hanya menjadi bagian dari data personal Anda.
  • Autentikasi Biometrik: Kami menggunakan sensor biometrik (sidik jari atau Face ID) yang ada pada perangkat Anda untuk fitur keamanan masuk (local_auth). Data biometrik ini diproses sepenuhnya secara lokal di perangkat Anda dan tidak pernah kami kumpulkan atau kami simpan di server.

2. Bagaimana Kami Menggunakan Informasi Anda

Informasi yang terkumpul semata-mata digunakan untuk tujuan:

  • Menyediakan, mengelola, dan memelihara aplikasi Personal Budgeting Anda.
  • Menyimpan dan mengamankan riwayat keuangan Anda secara sinkron berbasis Cloud.
  • Mengenali perintah suara secara real-time untuk mempercepat pencatatan pengeluaran (sementara dan langsung teks).
  • Melindungi keamanan akun dan transaksi Anda.

3. Layanan Pihak Ketiga

Aplikasi ini dapat menggunakan layanan dari pihak ketiga berikut yang memiliki Kebijakan Privasi mereka sendiri mengenai penanganan data Anda:

  • Google Play Services
  • Google Analytics untuk Firebase
  • Firebase Authentication & Firestore

Layanan pihak ketiga ini digunakan untuk fungsi autentikasi, database cloud backend, dan analitik stabilitas aplikasi (crash/error record).

4. Menghapus Data Anda

Anda memiliki kontrol penuh atas akun dan data keuangan Anda. Jika Anda ingin menghapus seluruh data Anda secara permanen dari server Firebase kami, Anda dapat menghapus akun langsung dari menu Pengaturan di dalam Aplikasi atau menghubungi tim dukungan kami.
